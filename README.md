# Lumen Reader

A screen reader for macOS, built on Apple's public accessibility APIs, with on-device AI that never
leaves your Mac.

- **Website:** https://mpaiva.github.io/lumen-reader/
- **Download:** none yet; Lumen Reader is in private testing

This repository holds the website and any public installers. It's published from the app's own
repository, so changes made here are replaced the next time it's published.
